<h1>Assignment 1 - Tab Generator</h1>
A Next.js app with manual CSS styling featuring a dark/light/system mode. This allows users to generate a tab interface from their own input (tab title and tab content)

<h1> Features</h1>
<ul>
  <li>Next.js frontend</li>
  <li>Manual CSS</li>
  <li>Syntax highlighting for HTML output using `react-syntax-highlighter`
  <li>Dark/light/system theme toggle</li>
  <li>Add/Remove/Edit tab</li>
  <li>Copy generated HTML output to clipboard</li></ul>

</ul>

<h1> Usage instruction</h1>
<ol>
  <li> Input tab information in the first column.</li>
  <li>Click <b>Add Tab</b> → the tab is displayed in the list.</li>
    <li>Select a tab → edit its title/content directly.</li>
  <li>Click <b>Generate Output:</b> <br>
   - If no content exists → a plain text message is shown. <br>
   - If content exists → an HTML code snippet for the tabbed interface is generated.</li>
  <li>Click <b>Copy</b> to copy the generated HTML to the clipboard.</li>
